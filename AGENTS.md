# Cat Hotel Simulator Development Instructions

## Project specifications

- Engine: Cocos Creator 3.8.8.
- Language: TypeScript.
- Genre: Casual cat hotel management simulator.
- Graphics: 2D cartoon with a top-down perspective.
- Orientation: Portrait 9:16, with a design resolution of 720 × 1280.
- Gameplay: Hybrid idle and active management.
- Controls: Mobile touch and tap.
- Target platform: TikTok Mini Games.
- Current scope: A small playable prototype.

## Mandatory art direction

Use `references/cat-hotel-artstyle-v1.png` as the primary visual reference for all game artwork, character designs, furniture, environments, and UI. Preserve its warm pastel colors, wooden floors, thick rounded dark outlines, adorable chibi cats, cozy atmosphere, and directly overhead perspective.

Do not switch to pixel art, realistic graphics, isometric graphics, or another cartoon style. Create individual game assets that match the reference rather than treating the reference image as a complete playable scene.

## Official development milestones

Follow these milestones in order. Do not expand the scope without the user's approval.

1. Game Design & Planning
2. Project Configuration & GitHub
3. Basic Layout (Greyboxing)
4. First Playable Gameplay Loop
5. Approved Cartoon Artwork
6. Expand & Balance Gameplay
7. Testing, Optimization & Publishing

## Development rules

- The user is a complete beginner. Explain technical changes in simple language.
- Use Cocos Creator 3.8.8-compatible TypeScript APIs.
- Preserve existing scenes, assets, and settings unless modifications are necessary.
- Prefer small, testable changes over large implementations.
- Do not introduce unnecessary dependencies or complicated architecture.
- Do not install packages, delete files, or perform destructive operations without approval.
- Do not commit or push Git changes unless explicitly requested.
- After each coding task, summarize modified files, explain how to test in Cocos Creator, and identify anything that could not be verified.
